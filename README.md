# ⌂ Калькулятор покупки недвижимости

Помогает сравнить **ипотеку сейчас или после накопления** и **покупку за накопления** с учётом роста цен на жильё, аренды, ремонта и доходности накоплений — и показывает, когда покупка и переезд станут доступными. Выбирает планы по раннему переезду, а не по минимуму суммарных затрат.

Все расчёты выполняются локально в браузере.

**Открыть:** https://vchekryzhov.github.io/home-purchase-calculator/

![Калькулятор покупки недвижимости — главный экран](docs/screenshots/desktop.png)

## Что отвечает калькулятор

**1. Ипотека — сейчас или после накопления взноса**

Посчитает, когда накопятся фактический первоначальный взнос и необходимый резерв для полного графика обязательств, и покажет условия кредита на тот момент: сумму, платёж, срок, переплату и дату последнего платежа. По умолчанию выбирается самый ранний выполнимый переезд.

Переключатель сценария погашения:

- **Максимально быстро** — после обязательных платежей все деньги сверх защищённого резерва идут на досрочное погашение, в том числе во время ремонта;
- **Растянуть на 30 лет** — договорной аннуитет без досрочных платежей; свободные деньги остаются в накоплениях и получают доход по ставке вклада.

**2. Копить до полной суммы**

Когда накоплений хватит на растущую цену квартиры и необходимый резерв, а также сколько вы заплатите за аренду до переезда. Ремонт оплачивается по тому же правилу «свободный доход + резерв», поэтому всю его стоимость не обязательно откладывать заранее.

**3. Квартира без ремонта**

Переключатель «Без ремонта» добавляет ремонт после покупки по единому правилу финансирования. Во всех стратегиях учитываются **дата переезда** и **аренда до переезда**: аренда продолжается до окончания работ, переезд = сделка + срок ремонта. По умолчанию выбирается самый ранний выполнимый переезд.

Месячный доход = сегодняшняя аренда + индексируемые накопления в месяц; способность откладывать растёт на процент индексации зарплаты и после покупки. Растущая аренда уменьшает доступную для накоплений часть дохода. Процент взноса — обязательный минимум; фактический взнос выше только тогда, когда иначе 30-летний аннуитет превышает месячный доход границы сделки. Сделка возможна лишь при накопленном фактическом взносе, не меньшем минимума, и достаточном резерве сверх него.

Стоимость ремонта индексируется к дате сделки и оплачивается равными платежами в течение срока работ. Часть покрывает свободный доход после аренды и обязательного платежа по кредиту, остальное и временный дефицит — заранее накопленный резерв. Весь договорной платёж по кредиту вносится по графику и во время ремонта.

Цель накоплений показана отдельно от полной стоимости ремонта:

- **Минимальный первоначальный взнос** и **Фактический первоначальный взнос**;
- **Накопить на ремонт** — необходимый начальный запас, а не полная стоимость работ и не часть, которую оплатит будущий доход;
- **Резерв на временный дефицит** — запас для обязательств без платежей ремонта;
- **Всего необходимых накоплений** — фактический взнос плюс накопления на ремонт и резерв на временный дефицит; при покупке за накопления вместо взноса используется полная цена жилья.

Необходимые накопления на ремонт и резерв учтены в датах покупки и переезда.

## Куда уходят деньги в месяц

Диаграмма — стековые свечи с реальными потоками по месяцам: тело кредита, проценты, ремонт, накопления и аренда. Аренда индексируется до переезда, а её сумма на графике совпадает с итогом карточки. Ремонт появляется только после сделки и оплачивается равными частями в месяцы работ. Проценты и погашение тела, включая досрочное, показаны за весь срок кредита — даже если выплата подходящего плана заканчивается за пределами 60-летнего горизонта поиска. Пунктирные линии — сделка и переезд выбранного плана.

«Накопления» на графике — оставшаяся часть месячного дохода после реальных платежей, а не весь запас денег; доход вклада в эту часть не входит. В быстром режиме излишек, направленный на досрочное погашение, включён в тело кредита. Месячные расходы могут превышать месячный доход, если разницу покрывает резерв: график показывает их полностью, без обрезки и скрытия дефицита.

График интерактивный: колесо мыши или пинч — масштаб, перетаскивание — прокрутка, полоса снизу — общий вид, наведение на свечу — точные суммы за месяц.

## Как считаем

- Месячный доход = сегодняшняя аренда + индексируемые накопления: M(m) = M0 × (1 + s/100)^(m/12), где M0 — накопления в месяц на старте, s — «Процент индексации зарплаты», m — месяцы от начала расчёта. Рост плавный и помесячный, продолжается после покупки без сброса счётчика месяцев. Индексируется только способность откладывать: арендная часть дохода остаётся сегодняшней, цена жилья, аренда и ремонт как расходы растут на коэффициент удорожания, доходность вклада — своя ставка. Ограничение issue #14 о фиксированном номинальном бюджете пересмотрено ровно в этой части; база в сегодняшних ценах (накопления + аренда) по-прежнему показывается как месячный бюджет. До сделки накопления получают месячную доходность вклада и пополняются остатком дохода после индексированной аренды. Если проиндексированная аренда превышает доход месяца, разница списывается из накоплений. Если продолжение аренды приводит к отрицательному остатку и выполнимой сделки на этой границе нет, более поздние даты ожидания недостижимы; нулевой остаток сам по себе не означает недоступность. При s = 0 доход каждого месяца равен базе в сегодняшних ценах, и расчёт в точности повторяет прежнее поведение фиксированного номинального бюджета.
- Фактический взнос — наименьший допустимый: максимум процентного минимума от цены на дату сделки и суммы взноса, необходимой, чтобы аннуитет на 360 месяцев не превышал месячный доход границы сделки — сегодняшняя аренда + проиндексированные накопления этого месяца. Этим проверка не исчерпывается: полный обязательный график обеспечивается последовательностью месячных доходов и резервом. Лишние деньги не увеличивают взнос. Для сделки нужны этот взнос и резерв, обеспечивающий полный обязательный график с неотрицательным остатком денег каждый месяц.
- Минимальный начальный резерв — максимум из нуля и накопленной дисконтированной нехватки денег по всем последовательным отрезкам графика от сделки до каждого очередного месяца. Для каждого месяца разница «обязательные расходы минус месячный доход» дисконтируется к границе сделки по месячной ставке вклада, затем эти разницы суммируются, включая отрицательные. Обязательный график включает аренду до переезда, договорную ипотеку и равные платежи ремонта. Ранние излишки покрывают поздний дефицит: сумму отдельных месячных недостач нельзя принимать за необходимый резерв.
- Резерв на временный дефицит равен минимальному резерву того же графика без платежей ремонта. «Накопить на ремонт» — разница между резервом полного графика и резервом без ремонта. Эти начальные запасы не пересекаются и в сумме точно дают общий резерв; это не сумма отдельных непокрытых платежей ремонта. Цель накоплений = фактический взнос + общий резерв.
- Ремонт индексируется к сделке и делится на равные платежи на весь срок работ. Свободный доход после аренды и обязательного аннуитета покрывает часть очередного платежа, остальное оплачивается из резерва. Переезд = сделка + срок работ; до этой границы аренда продолжается. Доход вклада не увеличивает месячный доход, а списание резерва не является новым доходом.
- Первый договорной платёж по кредиту вносится уже в месяц сделки. Проценты начисляются на остаток тела в начале месяца и полностью оплачиваются по графику: платежи не пропускаются, недоплата не капитализируется. Исходный аннуитет сохраняется до закрытия кредита, последний платёж может быть меньше. Переплата — сумма процентов за весь фактический срок; первоначальный взнос не учитывается повторно как погашение тела или расход месячного бюджета.
- В режиме «Максимально быстро» после обязательных платежей все наличные сверх защищённого резерва оставшихся обязательств идут на досрочное погашение, даже во время работ; защита пересчитывается при уменьшении тела. Досрочные платежи не увеличивают цель накоплений. В режиме «Растянуть на 30 лет» досрочных платежей нет, свободные деньги сохраняются и получают доход по ставке вклада; доходность ежемесячно начисляется и на резерв.
- Покупка за накопления использует тот же расчёт «доход + резерв», но без ипотеки: цель = цена жилья на дату сделки + накопления на ремонт + резерв на временный дефицит. Это отдельное сравнение, а не замена недоступного ипотечного плана.
- Поиск самого раннего ипотечного плана рассматривает даты сделки от 0 до 360 месяцев включительно; поиск по критерию «проценты ниже аренды» и сравнение покупки за накопления — от 0 до 720 месяцев. Во всех случаях переезд должен быть не позднее 720-го месяца, а срок кредита — не более 360 месяцев. Полный график подходящего плана, суммы процентов и тела и дата выплаты не обрезаются горизонтом поиска: кредит может завершиться после 720-го месяца от начала расчёта.
- Пороговый ипотечный план использует тот же взнос и резерв и дополнительно требует, чтобы проценты первого месяца были строго ниже индексированной аренды на дату сделки. Необязательный излишек не уменьшает эти проценты: досрочное погашение выполняется после первого договорного платежа. Выбирается самый ранний переезд среди подходящих планов, не глобальный минимум затрат.

## Запуск локально

Требуется Node.js 22+.

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # Vitest: модель и characterize-тесты
```

Продакшен-сборка:

```bash
npm run build    # результат в dist/
npm run preview  # локальный просмотр сборки
```

## Деплой

При пуше в `main` GitHub Actions собирает проект и публикует на GitHub Pages (`.github/workflows/deploy-pages.yml`).

## Стек

- [Vue 3](https://vuejs.org/) + [Vite](https://vite.dev/)
- Компонент `src/App.vue` + чистая финансовая модель в `src/lib/` (покрыта тестами Vitest)
- График — [ECharts](https://echarts.apache.org/) (зум, прокрутка, тултипы); без UI-библиотек

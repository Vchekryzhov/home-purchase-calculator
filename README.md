# ⌂ Калькулятор покупки недвижимости

Помогает решить, что выгоднее: **взять ипотеку сейчас** или **копить на квартиру**. Сравнивает три стратегии с учётом роста цен на жильё, аренды и доходности накоплений — и показывает, когда покупка станет доступной.

Все расчёты выполняются локально в браузере.

**Открыть:** https://vchekryzhov.github.io/home-purchase-calculator/

![Калькулятор покупки недвижимости — главный экран](docs/screenshots/desktop.png)

## Что отвечает калькулятор

**1. Ипотека — сейчас или после накопления взноса**

Если первоначального взноса пока нет — посчитает, через сколько месяцев он накопится, и покажет условия кредита на тот момент: сумму, платёж, срок, переплату и дату последнего платежа.

Переключатель сценария погашения:

- **Максимально быстро** — весь доступный платёж уходит в кредит;
- **Растянуть на 30 лет** — минимальный платёж.

**2. Копить до полной суммы**

Через сколько лет накопления догонят растущую цену квартиры и сколько вы заплатите за аренду за время ожидания.

**3. Когда покупать?**

Самый выгодный момент для покупки — когда проценты по кредиту за первый месяц станут **ниже аренды**: дальше жильё «в кредит» дешевле съёмного.

**4. Квартира без ремонта**

Переключатель «Без ремонта» добавляет сценарий ремонта после покупки. Во всех стратегиях появляется **дата переезда** и **аренда до переезда**: аренда продолжается, пока идёт ремонт, а платёж по кредиту в эти месяцы обслуживается только из ежемесячных накоплений — аренда переходит в ипотеку после переезда.

Финансирование ремонта — два режима:

- **Накопить до** — сделка ждёт, пока накопятся взнос и стоимость ремонта (обе суммы растут вместе с ценой недвижимости);
- **После покупки** — сделка на взносе; пока ремонт не оплачен, кредит обслуживается 30-летним аннуитетом, а излишек «накопления минус аннуитет» идёт на ремонт поэтапно. Переезд — когда завершены и работы, и оплата; после переезда свободные деньги ускоряют погашение.

## Куда уходят деньги в месяц

Диаграмма — стековые свечи по месяцам: тело кредита, проценты, ремонт, накопления и аренда. До сделки месячный бюджет делится между накоплениями и арендой; на ремонте аренда продолжается, а платёж по кредиту обслуживается из накоплений; после переезда аренда переходит в ипотеку. Пунктирные линии — сделка и переезд.

График интерактивный: колесо мыши или пинч — масштаб, перетаскивание — прокрутка, полоса снизу — общий вид, наведение на свечу — точные суммы за месяц.

## Параметры

| Параметр | По умолчанию | Пояснение |
| --- | --- | --- |

| Ставка кредита | 16,9 % | Годовая ставка по ипотеке |
| Первоначальный взнос | 20 % | Доля от цены |

## Как считаем

- Помесячная симуляция до 60 лет: цена квартиры и аренда растут на заданный процент, накопления — от доходности вклада плюс ежемесячных взносов.
- Доступный платёж по кредиту = ежемесячные накопления + аренда: после покупки деньги за съём переходят в ипотеку.
- Кредит считается доступным, когда взнос накоплен, а платёж позволяет погасить его максимум за 30 лет.
- Переплата считается по амортизационному графику с ежемесячной капитализацией процентов.
- Ремонт «накопить до»: цель — взнос плюс стоимость ремонта, обе суммы индексируются процентом подорожания; переезд = сделка + срок ремонта.
- Ремонт «после покупки»: сделка на взносе; пока ремонт не оплачен — 30-летний аннуитет и излишек «накопления минус аннуитет» на ремонт, переезд = сделка + max(срок работ, стоимость/излишек); после переезда — ускорение погашения.

Подробная методика — в блоке «Как считаем» на самой странице.

## Запуск локально

Требуется Node.js 22+.

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # Vitest: модель и characterize-тесты
```

Продакшен-сборка:

```bash
npm run build    # результат в dist/
npm run preview  # локальный просмотр сборки
```

## Деплой

При пуше в `main` GitHub Actions собирает проект и публикует на GitHub Pages (`.github/workflows/deploy-pages.yml`).

## Стек

- [Vue 3](https://vuejs.org/) + [Vite](https://vite.dev/)
- Компонент `src/App.vue` + чистая финансовая модель в `src/lib/` (покрыта тестами Vitest)
- График — [ECharts](https://echarts.apache.org/) (зум, прокрутка, тултипы); без UI-библиотек
